Kishi ハプティック試作

WebHID で Kishi のハプティック用インターフェースを開き、4 kHz の PCM を 64 バイトのフレームで送ります。 対象は Kishi V3 / V3 Pro / Ultra です。V3 Pro XL は別のプロトコルなので動きません。

ダイアログには Kishi のインターフェースがまとめて出ます。64 バイトの出力レポートを持つものを自動で選びます。 どれも出てこないときは、Kishi が XInput モードになっていて HID として見えていない可能性があります。

2. 振動子の設定

Feature report
強さ
値を直接送る

ON は値 1、OFF は値 0、強さは LOW = 0x21 / MEDIUM = 0x42 / HIGH = 0x64 を、左（1）と右（2）にそれぞれ送ります。 PeaSyo はどれも同じ形 00 振動子 値 で送っていて、値の意味の違いは実機で確かめる必要があります。
